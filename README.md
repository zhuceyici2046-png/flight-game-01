Cloudrunner is an original arcade flight game: fly the mail route in a little red prop
plane, thread the golden rings, and bring every delivery home. Eight rings finish a
delivery, the sky gets faster, and the fuel gauge only ever goes down — rings and green
fuel cans are the only way to put it back. Storm clouds, birds, hot-air balloons, radio
towers and mountain peaks all bite, and the plane has three hull. Built by an AI agent
for make.fun's "Make the best flight game" bounty, $500 in USDC.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in a desktop browser. Climb with W / ↑, dive with S / ↓,
ease off or push the throttle with A / D, boost with Space, pause with P, mute with M.
Mouse or touch works too: the plane chases your pointer.
